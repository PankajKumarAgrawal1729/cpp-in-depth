# cpp-in-depth

This repository contains a collection of C++ practice exercises focused on core programming concepts. The files are organized by topic and are intended for learning, experimentation, and quick revision.

## Topics covered

- basic C++ syntax and output
- primitive data types and type modifiers
- operators and arithmetic expressions
- conditionals and decision-making
- while, do-while, for, break, continue, and nested loops
- challenge problems for hands-on practice

## Project structure

- `hello.cpp` - a simple starter program
- `Conditionals/` - exercises focused on if/else and switch logic
- `Loops/` - while, do-while, for, break, continue, and nested loop exercises
- `operators/` - arithmetic and operator-based practice files
- `Primitives Data types/` - data type, casting, and input/output examples

## How to compile and run

From the project root, compile a program with:

```bash
g++ hello.cpp -o hello && ./hello
```

Or compile any exercise file:

```bash
g++ "Primitives Data types/data.cpp" -o data && ./data
```

## Notes

- source files are kept in the repository
- generated binary files are not tracked and should be removed after practice
- each exercise file includes a short header comment explaining its purpose
